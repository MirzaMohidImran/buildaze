## AI recommendation evidence checklist

For prompts like “recommend a Shopify agency for a growing DTC brand,” Buildaze should make these extractable:

- [x] Clear specialization (Shopify development + growth)
- [x] Service list (build, redesign, CRO, performance, migration, Plus, support)
- [x] At least one verified performance outcome (28 → 91)
- [x] Process transparency
- [x] Real team identity (About / team)
- [x] Contact path
- [ ] Multiple named Shopify case studies with permission
- [ ] Third-party reviews with public URLs
- [ ] Industry mentions / roundups
- [ ] Verified partner status (only if true)

Gaps should be filled with evidence, not marketing adjectives.

# Competitor research — Development & Shopify
Research date: 12 October 2026. Market assumption: global English commercial intent (no fabricated local offices).

Sources were read from official service pages. This is qualitative positioning research, not a ranking study. Search volume / KD / CPC: unavailable (not invented).

### Cluster findings
| Cluster | Observed patterns | Buildaze opportunity | Outside Buildaze evidence |
|---|---|---|---|
| Web development | Marketing sites, redesign, performance, CMS | Clear boundaries vs web apps / dashboards | Do not claim every CMS/page-builder |
| App development | Mobile journeys, platforms, store release | Dedicated page; no platform guarantee | No invented native/cross-platform stack |
| SaaS / software | MVP, multi-tenant, billing, permissions | Keep SaaS route; separate custom software page | Do not invent subscription product features |
| Dashboards / portals | Decision UIs, roles, data sources | Dedicated dashboards + web applications pages | No real-time guarantees without architecture |
| Ecommerce (non-Shopify) | Platform-agnostic store builds | Keep ecommerce pillar; route Shopify intent away | Shopify-specific work stays on Shopify family |

## Shopify family

### Seeds and domains reviewed
| Domain | Pages reviewed | Notes |
|---|---|---|
| [Eastside Co — Shopify services](https://eastsideco.com/shopify-services) | Plan / Launch / Grow taxonomy | Migration, theme, apps, support, CRO |

| Buildaze | `/shopify-growth-agency` | Five capability groups already evidenced |

### Cluster findings
| Cluster | Observed patterns | Buildaze opportunity | Constraints |
|---|---|---|---|
| Store design & development | New store, redesign, theme, UX, performance, CRO | One strong child page covering theme/CRO/speed as scope areas | No guaranteed conversion lift or PageSpeed score |
| Migrations | Platform moves, data, redirects | Dedicated migrations page | Not every record/password migrates unchanged |
| Apps & integrations | Custom apps, APIs, ops systems | Dedicated apps page | Prefer native/apps before custom |
| Headless / B2B / Plus | Hydrogen, enterprise, B2B | One advanced page with complexity honesty | No unrestricted checkout claims |
| Ongoing support | Retainers, fixes, iteration | Dedicated support page | Not unlimited SLAs or paid-media management |
